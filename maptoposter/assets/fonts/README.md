# Roboto

This directory bundles the Roboto font faces used by MapToPoster when
`font_family="Roboto"` (the default).

- Files: `Roboto-Regular.ttf` (400), `Roboto-Medium.ttf` (500), and
  `Roboto-Bold.ttf` (700)
- Source: [Google Fonts Roboto repository](https://github.com/google/fonts/tree/main/ofl/roboto)
- License: SIL Open Font License 1.1, included as `OFL.txt`

The font is registered with Matplotlib at runtime; no system-wide font
installation is required.
